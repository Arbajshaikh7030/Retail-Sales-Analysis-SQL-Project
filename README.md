## # 🛒 Retail Sales SQL Project

## 📌 Project Overview

This project analyzes retail sales data using SQL to uncover meaningful business insights related to sales performance, customer behavior, product categories, revenue generation, and profitability.

The project demonstrates practical SQL skills used in real-world data analytics and business intelligence projects.

---

## 🎯 Objectives

* Analyze total revenue generated from sales
* Identify top-selling product categories
* Measure monthly sales performance
* Find high-value customers
* Compare sales performance by gender
* Analyze customer age groups and buying behavior
* Identify peak sales hours
* Perform profit analysis
* Use SQL window functions for running totals and ranking
* Generate business insights using SQL queries
